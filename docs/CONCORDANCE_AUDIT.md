## Hard Findings From This Audit

- The public repo no longer tracks manuscript drafts, generated manuscript/SI
  HTML, publisher PDFs, or legacy code archives in the current head.
- The fake Dryad downloader was replaced by an explicit harmonized-data
  availability check. There is no longer a placeholder DOI in the active public
  run path.
- Kumagai comparator inputs that are small and publicly archived are now
  repo-controlled under `data/external/kumagai2024/`, so the main pipeline no
  longer depends on a user-specific home-directory mirror for scripts `15`,
  `16`, `18`, or `24`.
- The 2026-09-04 Table 3 implementation now matches the manuscript's stated
  Knapp-Hartung test. Under that test, the lobster-biomass to purple-urchin
  biomass relationship is directionally consistent but uncertain
  (`slope = -0.4215`, `SE = 0.1020`, `p = 0.0539`) rather than a conventional
  `p < 0.05` result.
- The manuscript and SI now use the same zero-correction description as the data
  code and data dictionary: half the minimum non-zero proportion within each
  source-specific MPA-taxon processing group, with inside-MPA and
  outside-reference values kept on the same scaling basis.
- The Supporting Information now has a dedicated resilience-support section
  that links main Figure 5 to sensitivity checks, Kumagai-style method/data
  bridges, environmental moderators, effectiveness prediction, compound
  disturbance checks, and Eisaguirre context.
- Script `20_compound_disturbance.R` now skips cleanly when optional raw PISCO
  inputs are absent instead of failing mid-script.
- The script-18 prose was stale: current tracked output gives kelp
  LOO-CV R2 = 0.401 but random-forest OOB R2 = -0.256, while purple-urchin
  prediction remains strongly negative. The updated interpretation is
  "weak and method-dependent", not "robustly predictable" and not "negative for
  every out-of-sample metric."

## Residual Risk

The public GitHub history still contains files removed from the current head,
including manuscript/PDF artifacts from older commits. If the sharing standard is
"the repository must never have distributed those files", this requires a
deliberate history rewrite or a fresh public repository. Current-head cleanup
alone does not erase prior public objects.
