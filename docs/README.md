# Analysis Documentation

This directory contains public, analysis-facing documentation for the California
MPA kelp-forest pipeline.

Current entry points:

- `RESULTS_SUMMARY.md` - machine-generated summary of the main analysis results.
- `RESILIENCE_SYNTHESIS.md` - plain-language guide to scripts `14`-`23`.
- `RESILIENCE_PIPELINE_INTEGRATION.md` - resilience claim-to-output audit trail.
- `CONCORDANCE_AUDIT.md` - manuscript/SI claim ledger tied to generated outputs.
- `ANALYSIS_REVISIONS.md` - historical comparison of the original analysis and
  the current reproducible pipeline.

Current manuscript drafts, cover letters, Supporting Information construction,
and citation-source PDF copies live outside this public analysis repository in
the private manuscript workspace. They are intentionally absent here.
