# Resilience Pipeline Integration

This file maps the resilience claims now used in the manuscript and Supporting
Information to the analysis products generated by this repository. It is meant as
the quick audit trail between the paper and the code.

## Run Path

The main reproducible pipeline is:

```r
source(here::here("code", "R", "run_all.R"))
```

`run_all.R` now runs the in-pipeline resilience modules after the core pBACIPS,
meta-analysis, temporal, figure, and moderator scripts:

The exact paper/SI concordance check uses the repo-controlled Kumagai comparator
inputs in `data/external/kumagai2024/`. Raw monitoring data are not needed for
`run_all.R`; raw PISCO is only needed to regenerate the standalone full-suite
modules `17` and `20`.

| Script | Role in paper/SI |
|---|---|
| `14_heatwave_analysis.R` | SI/discussion support: AR1 heatwave-window model and Kumagai-style context |
| `15_methods_comparison.R` | SI/discussion support: method-vs-data bridge against the Kumagai-style endpoint |
| `16_environmental_moderators.R` | SI/discussion support: tests the environmental covariates Kumagai mapped but did not model |
| `19_heatwave_replication.R` | SI/discussion support: two-heatwave repeatability |
| `21_resilience_stability.R` | SI/discussion support: stability is not the main resilience mechanism |
| `22_resistance_recovery.R` | Main text Figure 5 and main Results resistance/recovery paragraph |
| `23_ecological_memory.R` | SI/discussion support: reserve-level repeatability |
| `24_resilience_pipeline_check.R` | Concordance gate that fails if required artifacts or headline values drift |

The broader standalone suite is still available through:

```r
source(here::here("code", "R", "run_resilience.R"))
```

That adds the external-input modules `17_eisaguirre_reproduction.R`,
`18_mpa_effectiveness_predictors.R`, and `20_compound_disturbance.R` when their
raw PISCO or comparison inputs are available.

## Interpretation Guardrails

The pipeline supports a focused claim: southern California MPAs were associated
with stronger giant-kelp resistance and recovery during and after the 2014-2016
marine heatwave, and that foundation-species response is robust to several
analysis choices. It does not support saying that the full predator-urchin-kelp
mechanism is completely resolved. The manuscript should keep Kumagai et al. 2024
and Ortiz-Villa et al. 2025 as close comparator/context papers: they establish
the broader California MPA-kelp resilience context, while this repository tests
whether the result aligns across local paired MPA-reference units and trophic
responses.
