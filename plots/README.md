## Diagnostics

The `diagnostics/` subdirectory contains model diagnostic plots (DHARMa residuals, NLS diagnostics) generated during effect size calculation for quality control.

## Visual Conventions

- **Trophic order** (top → bottom): P. interruptus, S. pulcher, S. purpuratus, M. franciscanus, M. pyrifera
- **Axis scale**: Most effect-size figures display back-transformed Response Ratio (RR) ticks via `scale_y_rr()` / `scale_x_rr()`, with data internally on lnRR
- **Theme**: `theme_mpa()` — L-shaped axes, no gridlines, Helvetica, base_size = 9
- **All colors centralized** in `code/R/00b_color_palette.R`

## Export Format

- All figures exported as both PDF (vector) and PNG (600 DPI raster)
- Sized for Journal of Applied Ecology: single column = 80mm, double column = 170mm
- Colorblind-safe palette defined in `code/R/00b_color_palette.R`
